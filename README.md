# worthmyfee.com

Static landing page and privacy policy for Worth My Fee, served via GitHub Pages.

The application itself lives in a separate private repository.

## Search engines

- `sitemap.xml`, the card/credit pages and their JSON-LD are generated by `npm run pages` in the
  app repository; edit the hand-written pages (`index.html`, `privacy.html`, `terms.html`) here.
- IndexNow: `.github/workflows/indexnow.yml` waits for GitHub Pages to publish each push to main,
  then submits the changed pages that are in the sitemap (`scripts/indexnow.mjs`). The key file
  `f0290cd3888f72fc154819a874bea7b5.txt` must stay at the root. Run the workflow manually with
  "all" to resubmit every page. Tests: `node --test scripts/*.test.mjs`.
- The PostHog snippet in `index.html` (copied verbatim into every generated page) also carries a
  `crawler_hit` beacon for crawlers that run JavaScript; keep `privacy.html` and `terms.html` in
  sync with it (a test checks).
