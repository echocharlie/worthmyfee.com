# worthmyfee.com

Static landing page, card pages and privacy policy for Worth My Fee.

The application itself lives in a separate private repository.

## Hosting

- **Cloud Run** serves the site: service `worthmyfee-site` (project `worthmyfee`, `us-central1`),
  a small Express server in `server/` that serves this repo's files verbatim with GitHub Pages' URL
  rules and records which search engines and AI crawlers fetch them (PostHog `crawler_hit`).
  `.github/workflows/deploy.yml` tests and deploys every push to main. Runbook, log queries and the
  one-time setup: [docs/cloud-run.md](docs/cloud-run.md).
- **GitHub Pages** keeps building every push as the fallback; pointing DNS back at it is the rollback.
- Run locally: `cd server && npm ci && SITE_DIR=.. node server.mjs` (port 8080, or `PORT=…`).
- Tests: `node --test scripts/*.test.mjs server/*.test.mjs` (after `npm ci` in `server/`). There is
  no root `package.json`, on purpose.

## Search engines

- `sitemap.xml`, the card/credit pages and their JSON-LD are generated by `npm run pages` in the
  app repository; edit the hand-written pages (`index.html`, `privacy.html`, `terms.html`,
  `404.html`) here. `robots.txt` is hand-written.
- IndexNow: the `indexnow` job in `.github/workflows/deploy.yml` waits for the deploy and for GitHub
  Pages to publish each push to main, then submits the changed pages that are in the sitemap
  (`scripts/indexnow.mjs`). The key file `f0290cd3888f72fc154819a874bea7b5.txt` must stay at the
  root. Run the workflow manually with "all" to resubmit every page.
- The PostHog snippet in `index.html` is copied verbatim into every generated page; keep
  `privacy.html` and `terms.html` in sync with it (a test checks). Crawler reads are logged by the
  server, not by the snippet.
